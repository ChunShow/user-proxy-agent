## 단계 검증 기록 방식

각 계획에 실행한 명령과 결과, 화면 또는 실서비스 확인 결과, 남은 제한을 남긴다.
외부 서비스 검증은 호출 대상과 효과를 명시하고, 모사 시험 결과와 구분한다.
한 단계가 커지면 실행 전에 독립적으로 확인 가능한 작은 계획으로 나누어 컨펌받는다.
네이티브 앱 이식은 웹의 핵심 흐름을 검증한 뒤 별도 로드맵으로 다룬다.
