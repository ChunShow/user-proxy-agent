# 전화 없는 Live 한국어 음성 품질 개선

상태: completed (1차 API 비교·설정 적용). 한국어 청취 품질의 최종 판정은 남아 있다.
승인 근거: 사용자가 기존의 끼어들기 정책 전후 비교 → 출력/재생 계측 → 필요한 중계 보완,
한국어 말투·발음·음성 비교 방안을 직접 인용하고 “이 문제 좀 이제 해결해 줄래”,
“통화 연결 없이 API호출해서 ... 최대한 자연스러운 한국어 대화 설정을 찾고 싶어”라고 요청했다.
이 구체적 방향을 이번 작업의 승인 범위로 적용한다. 실제 발신·Google 작업은 없다.

## 범위와 작은 작업 단위

1. 기존 Live API와 bridge를 이용하는 독립 음성 실험을 준비한다. 합성 한국어 입력을 동일하게
   반복하고 원본 모델 출력과 가짜 회선으로 전송된 출력을 별도 저장한다. 실제 ClawOps 연결은 금지한다.
2. 현행 지시/명시적 끼어들기·한국어 구어체 지시를 비교한다. 일상 문답, 시간 정정 중 끼어들기,
   맞장구를 구분한다. 동일 입력·속도·PCMU 8kHz 조건에서 여러 차례 확인한다.
3. endpoint가 받아들이는 음성 후보를 제한적으로 비교한다. 지원 여부와 자연스러움은 구분한다.
4. 음성 간격, 원본과 중계 바이트 보존, 출력 적체, 입력 중 실제 출력 정지와 정정 반영을 계측한다.
   무조건 에너지 기준 clear는 넣지 않는다. 인과 증거가 있는 결함만 회귀 테스트 후 수정한다.
5. 개선 지시/검증된 설정과 재현 가능한 실행 스크립트를 반영한다. 기존 종료/위임 회귀를 검사한다.
   음성 샘플과 결과는 ignored var에 저장하고, Git에는 합성 시나리오·지표·한계만 기록한다.

## 파일/인터페이스

- scripts/check_live_korean.py: 명시적 --run, 제한된 세션 길이/실험 조합, 새 출력 디렉터리.
- calls/live.py, calls/settings.py: 검증 후 대화 지시/음성 설정. 기존 endpoint/key 재사용.
- calls/live_bridge.py: 증거가 있는 경우에만 음성 중계 수정.
- backend/tests/calls/: 영향 범위 회귀 검사.
- docs/research/ 및 이 계획/roadmap: 검증 결과와 다음 제한.

## 완료 기준

실제 Live API에 합성 음성을 입력한 전후 결과·재생 가능한 샘플·반복 실행 명령을 남긴다.
자연스러움은 전사만으로 합격 처리하지 않으며, 객관 지표와 사람의 청취 평가를 구분한다.
실회선 품질·잡음/에코·실제 사용자의 억양을 검증한 것으로 보고하지 않는다.
실험으로 입증되지 않는 음성의 우열이나 완전 해결을 주장하지 않는다.
세션별 상한 45초, 1차 최대 12세션으로 시작하며 중간 결과에 따라 불필요한 조합을 줄인다.


## 실행 결과

[1차 실험 결과](../../research/2026-09-27-live-korean-experiment.md)에 방법·수치·제한을 기록했다.
9개 유효 실제 API 음성 실행, 3개 실험 도구 오류 제외. 세 음성 지원·정정 반영·맞장구·일반
문답을 확인하고 개선 지시를 제품에 반영했다. 기본은 marin이며 음성 선택지와 세션 응답
검증을 추가했다. 음량 기준 강제 중단이나 중계 버퍼 변경은 증거가 불충분해 넣지 않았다.

테스트 먼저: 음성 선택/잘못된 세션 음성 거부, 무음 계측/네트워크 공백 구분/겹침 시간/
실험 시간 제한의 실패를 확인한 뒤 구현했다. 관련 회귀 58개, backend/scripts Ruff 통과.
Ruff는 프로젝트의 기존 검사처럼 backend cwd에서 실행해야 src import 분류가 일치한다.
실험 WAV는 현재 도구로 직접 들을 수 없으므로 자연스러움 평가를 꾸며서 보고하지 않았다.
원본·모사 재생 비교 페이지를 사용자에게 제공했고 선호 확인 전에는 marin을 유지한다.
backend 재시작 후 health 정상이며 실제 전화/Google 작업은 없었다.


사용자 청취 후 “개선 지시 · marin · 1 이거 괜찮은 거 같아”라는 피드백을 받았다.
현재 지시/음성 설정이 선택한 샘플과 동일함을 확인하고 기본값을 유지했다.
실제 회선의 간헐 끊김 원인과 다양한 화자 검증은 계속 남아 있다.
