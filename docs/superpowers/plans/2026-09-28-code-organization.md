# 업로드 전 코드 책임 분리

상태: completed
승인: 사용자가 2026-09-28 “파일구조의 재배치와 코드베이스의 리펙토링이 필요하면 진행해줘.”라고
요청했다. 직전 범위 선택에 따라 `agent-service`만 작업하며 동작을 보존하는 내부 정리를 진행한다.

## 확인한 문제

- 통화 위임이 `chat.runtime.build_agent`를 함수 안에서 가져와 순환 의존을 피하고 있다.
  공통 DeepAgents 생성 정책을 채팅이 소유해 통화가 채팅 구현에 결합돼 있다.
- 통화·Google·실행 카드의 HTTP 요청이 `chat/conversations.ts`를 가져오고 오류는
  `chat/stream.ts`에 있다. 공통 전송 처리가 대화 기능에 섞여 있다.
- 웹의 통화 카드·음성·전사·상태 훅이 모두 `chat/`에 있어 기능 경계를 찾기 어렵다.
- 긴 시스템 프롬프트가 소켓/위임/채팅 실행 코드 안에 들어 있다.

## 변경 범위

1. 공통 `agents/factory.py`에 도구 제한과 에이전트 생성만 분리한다. 채팅의 기본 프롬프트
   선택은 기존 채팅 진입점에 유지하고, 통화는 공통 팩토리에 직접 의존한다.
2. 채팅 프롬프트는 `chat/prompts.py`, Live·통화 업무·결과 보고 프롬프트는 `calls/prompts.py`로
   옮긴다. 추출 전후 문자열을 비교하며 모델/프롬프트/timeout/재시도 정책을 바꾸지 않는다.
3. 공통 HTTP와 오류를 `web/src/api/`로 분리한다. 통화 파일·관련 단위 검사는
   `web/src/calls/`로 옮기고 호출부/테스트 명령을 갱신한다. 화면·CSS·API 계약은 유지한다.
4. 새 구조와 의존 방향을 문서화하고 작은 단위로 로컬 커밋한다.

외부 API 호출·실제 전화·Google 쓰기·DB 마이그레이션·모델 변경·이력 재작성은 하지 않는다.
음성 중계의 상태 머신이나 저장소의 트랜잭션을 파일 길이만으로 쪼개지 않는다.

## 검증

- 변경 전 기존 에이전트 도구 제한·취소·위임 검사와 웹 단위 검사 실행.
- 공통 HTTP의 기존 계약(메서드/쿠키/JSON/204/오류/취소)을 특성 검사로 고정한 후 이동.
- 프롬프트 원문 동일성, 전체 backend/web 검사·정적 검사·빌드.
- import 이동이 실제 앱 흐름에 미치는 영향을 모사 브라우저 회귀 검사로 확인.
- Git diff와 문서 로컬 링크 검사. 런타임 데이터와 개인 설정은 보존한다.

## 검사 중 발견한 기존 정리 사항

- 전체 검사에서 평가 스크립트의 긴 줄과 실행 디렉터리에 따라 달라지는 Ruff import 분류가
  드러났다. 사례 문자열은 동일하게 보존하고 명시적인 import 분류를 설정했다.
- 브라우저 검사가 기존 `docs/verification` 이미지를 덮어썼다. 실행 시 이미지는
  `test.info().outputPath`의 Git 제외 경로로 저장하고 기존 이미지는 유지한다.
- 브라우저 56개 중 2개가 예전 종료 안내 문구를 기대했다. 해당 제품 함수는 이전 커밋과
  바이트 단위로 동일했다. 이미 구현된 종료 주체 미확인·재생 증거 구분에 맞춰 기대 문구를
  갱신했으며 정확한 문구와 새로고침 후 복원 검사는 유지한다.

## 완료 결과

- 공통 에이전트 팩토리와 4개 프롬프트를 분리했다. 프롬프트는 이전 커밋의 문자열과 모두
  일치한다. 통화 위임의 함수 내부 채팅 import를 제거했다.
- 웹 통화 파일 12개와 관련 테스트를 `calls/`로, health·JSON 요청·공통 오류를 `api/`로
  모았다. 새 HTTP 특성 검사 5개는 이동 전후 모두 통과했다.
- 전체 `./scripts/check.sh`: backend 331개·web 55개, Ruff·TypeScript·ESLint·빌드 통과.
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`: 56개 통과. API와 전화는 모사했다.
- 문서 로컬 링크 검사와 `git diff --check` 통과. 재실행 후 과거 검증 이미지 변경 없음.
- 평가 사례 입력·판독 기준은 AST 값 비교로 이전 커밋과 동일함을 확인했다.
- 제품 `.env`·데이터·DB 스키마·화면 DOM/CSS·공급자 설정은 유지했다. 유료 모델/실제 전화/
  Google API 호출과 실행 중인 제품 서버 재시작은 하지 않았다.

현재 구조와 의존 방향은 [코드 구조](../../code-structure.md)에 정리했다. 소켓/음성 큐/종료
상태 머신은 결합된 동작이므로 이번에 파일 길이만 줄이려고 분리하지 않았다.
