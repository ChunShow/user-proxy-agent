# 통화 말투와 질문 반복 개선

상태: complete. 사용자가 현재 시스템 프롬프트 확인과 길고 어색한 통화 말투의 조정을 요청했다.
현재 Live 지시는 일반적인 '한두 문장/질문 하나' 수준이며, 선호 없음의 수용·불필요한 재질문·
매 답변의 감사/설명·종료 판단 대기 멘트에 대한 구체적인 기준이 없다.

같은 gpt-live-1/marin/발음·끼어들기 정책을 유지하면서 보통 한 짧은 문장, 담백한 해요체,
직접적인 질문, 선호 없음 수용, 의미 없는 재확인/대기 멘트 감소를 반영한다. 예약·날짜·시간 등
실행에 필요한 정보가 없으면 구체적인 확인 하나를 유지한다. 요청자가 구체적 결정까지 맡긴
경우는 단순 선호 조회와 구분한다. 업무 담당 DeepAgents도 같은 기준으로 완료 여부를 판단한다.
메인 에이전트가 만드는 시작 멘트도 AI 소개와 통화 목적/질문을 짧게 구성하도록 지시한다.
명시적으로 지정한 시작 문구는 존중한다. 도구/권한/사용자 확인/종료 처리 구조는 유지한다.

검증은 기존 통화 회귀와 전화 없는 합성 한국어 음성의 실제 Live API 비교로 진행한다.
단순 프롬프트 문자열 검사를 품질 검증으로 대신하지 않는다. 화자의 자연스러움 자체는
자동 수치만으로 확정하지 않고, 생성된 문장 길이/재질문/대기 멘트 및 음성 자료를 남긴다.
공식 근거: https://developers.openai.com/api/docs/guides/live-prompting


## 결과

- Live 말투, DeepAgents 완료 판단/발화, 메인 에이전트의 시작 멘트 생성 지시를 조정했다.
  모델과 음성, 끼어들기/종료 구현, 외부 실행과 승인 구조는 변경하지 않았다.
- 통화 회귀와 메인 채팅 테스트 223개 통과, 수정 파일 Ruff와 diff 검사 통과.
- 실제 gpt-live-1/marin에 같은 Yuna 합성 한국어 음성을 넣어 이전/수정 설정을 각 25초씩
  비교했다. 입력: “딱히 가고 싶은 곳은 없어요. 아무 데나 괜찮아요.”
  이전: “네, 알겠습니다. 그럼 내일은 특별히 가고 싶은 장소는 없는 걸로 이해할게요.
  다른 얘기 도와드릴 게 있을까요?”
  수정: “네, 특별한 선호가 없으시다고 그대로 전할게요.”
  두 세션 모두 오류 없이 음성 출력. 수정 응답에서는 불필요한 추가 질문/대기 멘트가 없었다.
- 이 비교에서는 위임 이벤트가 양쪽 모두 발생하지 않았다. 모사 백엔드 응답 경로는 실행되지
  않았으며 종료 판단이나 자동 종료의 실제 모델 검증으로 간주하지 않는다. 한 건의 합성 비교로
  전체 한국어 자연스러움을 보장하지 않는다. 실제 발신/Google 실행은 하지 않았다.
- 원본 프롬프트, 평가 드라이버, 입력/출력 WAV와 전사는 ignored var/natural-dialogue-lab 및
  var/check_natural_dialogue.py에 보관했다. 합성 테스트 파일은 Git에 포함하지 않는다.
- 진행 중 채팅/통화/외부 실행이 모두 0건임을 확인하고 로컬 서비스를 재시작했다.
  backend 9010 / web 5180 HTTP 200 확인. 새로 시작하는 통화부터 반영된다.
