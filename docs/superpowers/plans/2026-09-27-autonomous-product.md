# 남은 제품 기능의 자율 진행

상태: completed (승인 범위의 구현·모사·로컬 반영). 2026-09-27 사용자의 개입 없이 가능한 남은 작업을 최대한 수행하라는 요청으로 승인됨.
원문 요지: “내 개입 없이도 너가 할 수 있는 작업들 최대한으로 … 최대한 완성도가 있는 프로덕트”.
기존 단계별 추가 컨펌은 이번 작업에 한해 생략한다. 순차 구현·테스트·기록·작은 커밋은 유지한다.

1. 9·10단계: 공통 Google 계정 연결, Calendar/Gmail 조회 도구와 설정 화면.
2. 11단계: 연결 앱의 조회 결과를 채팅/전화 위임에 활용하고 출처·미확인 상태를 구분.
3. 12단계: 일정 등록·메일 발송의 구체적 실행안과 사용자 확인, 중복 실행 방지. 실제 외부 쓰기는 하지 않음.
4. 기존 제품의 오류·복원·모바일·접근성 점검, 전체 회귀 검증 및 사용자 시작 안내.
5. 브라우저 통화 듣기와 자동 종료 개선도 포함한다. 사용자가 “둘 다 포함해 주세요”라고 답했다.
   실제 발신 없이 음성 스트림과 종료 경합을 모사 검증한다.

각 묶음을 시작할 때 해당 단계 계획을 작성한다. OAuth 자격증명은 현재 프로젝트에 없으므로
실제 계정 연결은 설정과 사용자 로그인·동의가 남는다. 이것이 독립적인 구현/모사 검증을 막지 않는다.
코드는 현재 전용 feature branch에 작은 커밋으로 남긴다. 자동 발신이나 유료 실제 모델 반복 실험은 하지 않는다.

사용자는 Google Calendar + Gmail, 개인용 로컬 웹 서비스 완성을 명시적으로 선택했다.

## 완료와 제한

Google 읽기→통화 일정 확인→확인 후 쓰기, 브라우저 듣기, 종료 취소 기록·완료 보조 점검을 순차 구현했다.
최종 검증은 `2026-09-27-local-product-quality.md`에 기록했다. 세부 작업별 로컬 커밋으로 남겼다.
기존 설정·대화를 보존하고 서버에 반영했다. 실제 계정 동의와 실제 Google/새 실통화 확인은 사용자와 나중에 진행한다.
