# README 구조도 다시 그리기

- 상태: complete
- 범위: README 구조도와 편집·내보내기 자료. 서비스 동작 변경 없음.
- 요청 근거: 사용자가 기존 구조도가 이상하다고 평가하고 “구조도 그리는데 필요한 스킬을
  써서 다시 그려줘. 시각적으로 보기 좋게”라고 직접 수정을 요청했다.

## 작업

1. 정적 문서용 diagram-design 스킬의 architecture·Mermaid redraw 지침을 읽는다.
2. 웹 → 로컬 백엔드 → 외부 공급자의 세로 구조로 수동 배치한다.
3. HTML 원본에서 SVG·고해상도 PNG를 만들고 README에 연결한다.
4. 접근성·XML·문서 링크와 README 너비의 시각 결과를 확인한 뒤 커밋한다.

## 결과

- 겹치는 연결선 없는 960×960 도식, 1920×1920 PNG와 확대 SVG.
- 텍스트 모델과 통화 상대는 관련 카드에 묶고 SQLite·Langfuse는 분리했다.
- 직접 제어·승인 및 저장·추적의 생략된 선을 README와 편집 안내에 명시했다.
- 스킬 self_check 통과, SVG XML 파싱·원본 일치·로컬 링크 검사 통과.
- 830px 너비 이미지에서 한글과 연결선을 시각 확인했다. 모든 글자가 캔버스 안에 있다.
- 기존 웹 Playwright 의존성으로 내보내기를 재실행했다. 제품 서버·외부 API는 사용하지 않았다.
