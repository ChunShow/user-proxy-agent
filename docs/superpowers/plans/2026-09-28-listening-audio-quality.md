# 브라우저 통화 듣기 잡음 조사·개선

상태: complete
승인: 사용자에게 원본/브라우저 재생 비교와 재생 틈 측정을 제안한 뒤, 사용자가
“진행해줘.”라고 명시적으로 승인했다(가상 ARS 지지직 잡음 제보 후).

## 범위와 순서

1. ARS 원본·μ-law 변환의 클리핑/변환 오차 확인, 기존 플레이어의 지터 재현.
2. 확인된 재생 결함만 수정. 양쪽 트랙·중단·대기량 제한·브라우저 자원 해제를 유지한다.
3. 원본 및 일정한 입력/지터 입력의 전후 파형 비교, 회귀 테스트·타입·lint·빌드 검증.
4. 공유 정적 웹에 빌드 반영, 결과·한계 기록 후 로컬 커밋.

대상: `web/src/calls/callAudio.ts`, 관련 단위/브라우저 검사, 필요한 평가 도구와 문서.
통화 모델·실회선 전송은 변경하지 않으며 실제 전화는 걸지 않는다.
완료 기준: 재현한 짧은 도착 지터에서 재생 틈 제거, 음성 샘플 보존, 즉시 중단 및
과도한 지연 뒤 복구 유지. 물리 청감은 측정 결과와 구분해 보고한다.

## 결과

재생 공백과 개별 조각의 재샘플링 오차를 각각 실패 테스트로 재현하고 수정했다.
웹 단위 59개, Chrome의 파형·듣기 회귀 3개, lint·타입·빌드 통과.
공유 HTTPS의 새 정적 번들 일치를 확인했다. 현재 사용자의 통화와 서버는 재시작하지 않았다.
자세한 지표·전후 비교·재실행 방법·한계는
[청취 평가 기록](../../evaluations/2026-09-28-listening-audio-quality.md)을 따른다.
