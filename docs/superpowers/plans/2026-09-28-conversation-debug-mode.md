# 같은 웹에서 디버깅 대화 생성

상태: complete
승인 근거: 사용자가 독립 웹 대신 하나의 웹에서 좌측 하단 디버깅으로 새 대화를 만들고,
그 대화만 ClawOps 대신 가상 ARS로 연결하는 방식으로 변경해 달라고 요청했다.
이번 변경은 기존 가상 ARS 기능의 진입점과 대화별 연결 선택 통합이다.

## 설계

- 좌측 하단 `디버깅` 버튼은 새 가상 통화 대화를 만든다. 일반 새 대화는 기존 실제 통화 모드.
- `conversations.mode`는 `real | simulation`, 기존 데이터 기본값은 real.
  생성 후 변경 API는 없다. 동일 ID 재요청으로 모드가 변경되지 않는다.
- 서버가 대화 모드를 읽어 통화에 저장한다. 모델이 공급자/모드를 선택하지 않는다.
  승인·실행·조회·재시작 종료 처리 모두 저장된 모드에 따라 같은 공급자로 연결한다.
- 가상 모드에서는 기존처럼 Google 조회·쓰기 도구를 제외하고 전화 도구와 사용자 확인을 쓴다.
- 가상 ARS 서버는 9020의 독립 프로세스로 유지한다. 별도 5181 웹/9011 백엔드는 더 이상
  기본 진입점으로 사용하지 않는다. 기존 5180과 공유 주소에서 같은 기능을 사용한다.
- 안내/키 준비와 ARS 시작은 개발 실행기에 통합한다. 통화는 카드 승인 전 시작하지 않는다.
- 이전 별도 디버그 DB는 보존하고 자동 합치지 않는다.

## 화면 방향

기존 중립색·글꼴·44px 버튼 간격을 유지한다. 하단 플라스크 아이콘+디버깅, 대화 목록의
작은 가상 통화 표시, 선택한 대화 상단의 실제 발신 없음 안내만 추가한다.
모바일 메뉴에서도 같은 동작을 제공하고 접힌 사이드바에는 버튼 이름을 접근성으로 남긴다.

## 검증 결과 — 2026-09-28

- `./scripts/check.sh`: backend 365개, web 56개, Ruff/TypeScript/ESLint/운영 빌드 통과.
- 회귀 검사: 생성/조회/목록의 모드 유지, 동일 ID 모드 변경 거부, 소유권, 가상 카드의
  승인 전 연결 0회, 실제 설정 로더 미호출, 복구 시 가상 공급자 유지, 가상 공급자 초기화
  실패 시 슬롯 해제. 기존 실행기 프로세스 검사는 `VIRTUAL_ARS_ENABLED=0`으로 포트를 격리한다.
- 기존 5180 웹에서 디버깅 클릭 → 실제 모델 카드 생성 → 새로고침 → 가상 승인 →
  Live-1의 4/2 선택 → 진료 안내 전체 수신 → end_call(goal_achieved) → 종료 API 완료.
  실제 통신사 발신 0회. `digits=[4,2]`, `hours_delivered=true`,
  `end_reason=hangup_requested`, 회선 completed, 연결 후 약 50.6초.
- 일반 새 대화에서 실제 모드 승인 카드 생성 후 취소. provider_call_id와 dial_attempted_at
  모두 null. 실제 번호로 연결하지 않았다.
- Chrome 기본 화면과 390×844에서 메뉴 하단 버튼·모드 표시·카드 구분 확인.
  모바일 메뉴에서 디버깅을 누르면 메뉴가 닫히고 같은 웹에서 새 가상 대화가 열린다.
- 실행 중 통화 0건 확인 후 SQLite 온라인 백업을 만들고 통합 실행기를 적용했다.
  5180/9010/9020 사용, 이전 5181/9011 프로세스 종료. 기존 공개 프록시 구성은 유지했다.
- 증거와 백업은 Git 제외 `var/unified-debug/`에 보관했다. 이전 분리 DB는 보존한다.

## 제한

- 가상 ARS는 기존 고정 진료시간 시나리오 하나다. 모델의 매번 같은 메뉴 선택이나 자연스러움을
  보장하는 평가는 아니며, 앞 단계의 위임/보고 품질 과제는 남아 있다.
- 실제 모바일 앱 내 브라우저/실회선 재발신은 이번 검증에 포함하지 않았다.
- 모델 호출 비용은 기존 API에 발생한다. 새 외부 전화/TTS API 가입은 필요 없다.
- 대화는 첫 메시지에서 영구 저장한다. 빈 디버깅 화면은 `?debug=1`로 새로고침해도 유지된다.
- 기능 모드는 생성 후 바꾸지 않는다. 다른 모드는 새 대화를 만들어 사용한다.
