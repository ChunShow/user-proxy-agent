# 사이드바 정리와 너비 조절

상태: complete
승인 근거: 사용자가 이번 요청에서 삭제한 대화창 제거, User Proxy Agent 로고,
자유로운 사이드바 크기 조절과 새 대화 아이콘 개선을 직접 지시했다.

기존 채팅 UI의 흰색/회색 팔레트와 시스템 글꼴을 유지한다. 조용한 모노그램과 두 줄 워드마크를
좌상단에 배치하고, 새 대화는 선명한 펜 아이콘을 사용한다. 색상은 기존 canvas #f7f7f6,
surface #ffffff, ink #262626, muted #6a6a67, line #e5e5e3를 따른다.
삭제한 대화 메뉴/복원창을 제거하고 삭제 안내를 화면의 실제 동작에 맞춘다. 기존 저장 데이터의
물리적 삭제나 백엔드 API 변경은 포함하지 않는다.

오른쪽 경계를 드래그해 데스크톱 사이드바 너비를 조절한다. 최소 232px, 최대 440px/화면 45%,
기본 272px. 브라우저 로컬에 선호 너비를 저장한다. 접기/펼치기, 창 크기 변경과 모바일 메뉴를
함께 유지한다. 키보드 방향키, Home/End와 더블클릭 기본값 복원도 지원한다.

작업: 목록 UI 정리 → 로고/아이콘 → 너비 조절 → 웹 자동 검사/실제 브라우저 확인 → 로컬 커밋.
검증: 너비 제한/저장값 오류, 삭제 메뉴 제거, 드래그/키보드/새로고침 유지, 접기/펼치기,
데스크톱/모바일 넘침과 조작 확인. 외부 모델/전화/Google 실행은 없다.


## 완료와 검증

- 삭제한 대화 메뉴와 복원창/프론트엔드 호출을 제거하고 삭제 안내를 변경했다.
- UP 심벌과 User Proxy / Agent 워드마크, 새 대화/접기 아이콘을 적용했다.
- 경계 드래그, 방향키, Home/End, Enter/더블클릭 초기화와 로컬 너비 저장을 구현했다.
- 웹 자동 테스트 50개, ESLint, TypeScript/프로덕션 빌드 통과.
- 실제 Chrome에서 드래그 272→366px, 왼쪽 키 350px, 새로고침 후 350px 유지,
  접기/펼치기 후 유지, Home 232px/End 440px/Enter 272px를 확인했다.
- 390×844 모바일 메뉴의 로고/이전 목록/새 대화 동작과 데스크톱 복원을 확인했다.
  데스크톱 scrollWidth와 clientWidth는 1745px로 일치했다. 뷰포트 재설정 완료.
- 기존 Playwright 삭제/복원 시나리오는 새 UI에 맞게 갱신했다. 이번에는 Playwright 전체
  스위트를 실행하지 않았고, 위 자동 단위 검사와 실제 브라우저 조작으로 검증했다.
- 최종 로컬 화면: ignored var/sidebar-polish.png. 새 대화 화면으로 열어두었다.
  저장 데이터 삭제나 모델/전화/Google 실행 없이 Vite에 반영됐다.

## 사용자 피드백: 이름만 표시

사용자가 로고 대신 이름만 담백하게 표시하고 새 대화 아이콘을 다시 수정하도록 요청했다.
심벌과 두 줄 워드마크를 없애고 한 줄의 User Proxy Agent를 14px/500으로 표시한다.
새 대화는 장식 없는 더하기 아이콘으로 바꾼다. 기능 변경 없이 빌드와 실제 화면을 확인한다.

후속 수정 검증: ESLint·TypeScript·빌드 통과. 실제 브라우저에서 한 줄 이름과 더하기 아이콘 확인.
