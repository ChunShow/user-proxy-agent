# GPT-Live 끼어들기·한국어 음성 조사

후속: [전화 없는 API 비교와 설정 적용 결과](2026-09-27-live-korean-experiment.md).
이하 내용은 개선 전 조사 기록이다.

2026-09-27 사용자 관찰: 도우미가 말하는 중 상대가 말해도 멈추지 않으며 한국어가 더 자연스럽기를 원함.
현재는 코드·공식 문서 조사 결과이며, 해당 증상의 실제 원인 확정이나 수정 완료를 의미하지 않는다.

## 공식 자료

- https://developers.openai.com/api/docs/models/gpt-live-1
  GPT-Live는 듣기와 말하기를 동시에 수행하고 끼어들기에 대응하는 모델이다. Fine-tuning은 지원하지 않는다.
- https://developers.openai.com/api/docs/guides/live-prompting
  짧은 대화 지시와 Backchannel/Interruption/Delegation 정책을 권장한다.
  상대가 끼어들면 답변을 멈추고 듣는 정책, 목표 언어의 지시·예시·발음 단서를 권장한다.
- https://developers.openai.com/api/docs/guides/live-conversations
  음성은 세션 시작 시 선택한다. 기본은 marin이며 추가 음성 목록이 있다.
  각 음성의 목표 언어·발음을 직접 시험해야 한다. 한국어 최적 음성은 이 문서만으로 정할 수 없다.
- https://developers.openai.com/api/docs/guides/voice-server-controls?api=live
  출력 제어는 앱/미디어 중계에서 수행한다. 보류 음성 폐기와 재생 복구는 별도 정책이 필요하고,
  명령 ACK 자체는 재생 재개 신호가 아니다. 입력 mute는 출력 중단이나 업무 취소가 아니다.

## 확인한 구현

- calls/live.py의 INSTRUCTIONS에는 한국어로 자연스럽고 짧게 말하라는 지시가 있으나
  끼어들기 양보 정책과 한국어 억양·구어체·숫자 발음 예시는 없다.
- calls/settings.py는 CALL_LIVE_VOICE 값을 marin 하나로 제한한다.
  공식 API의 음성 지원 범위와 현재 앱의 허용 범위는 다르다. 실제 Azure endpoint 지원 여부도 검증해야 한다.
- calls/live_bridge.py의 phone()은 입력 음성을 계속 모델로 전달한다. 입력 음성 활동을
  종료 대기 취소에는 사용하지만 일반 발화의 출력 큐 정리에는 연결하지 않는다.
- _clear_output()은 로컬 큐와 ClawOps 재생을 비우는 기능이 있으나 통화 정리 시에만 사용한다.
- Realtime의 bridge.py는 speech_started에서 출력 큐 정리·응답 취소·문맥 절단을 처리한다.
  Live는 연속 스트림이므로 Realtime 이벤트/명령을 그대로 보내는 해결책은 적용하지 않는다.
- 출력 큐는 20ms 단위 250패킷 용량이다. 최대 용량이 5초라는 뜻이지 실통화에서 5초가
  쌓였다는 증거는 아니다. 실제 큐 깊이·회선 ACK 지연·모델 음성 정지 시각을 측정해야 한다.
- 현재 전화 경로는 PCMU 8kHz다. 모델 출력 샘플레이트만 올려도 기존 전화 경로의
  음질 제한이 사라지는 것은 아니다.

## 최근 통화의 제한된 계측

최근 통화의 audio_progress 26개 표본에서 generated-sent 차이는 최대 80ms,
sent-ACK 차이는 최대 160ms였다. 후자는 재생 완료 시각의 정확한 지연이 아니라 ACK 간격도
포함한다. 약 1초 간격 표본이므로 순간 적체나 사용자가 지적한 특정 겹침 구간을 증명하지 않는다.
이 자료로 큰 출력 큐 적체를 원인이라고 확정할 수 없다.

## 판단과 후속 검증

모델이 원래 끼어들기를 지원하지 않는다고 설명할 수 없다. 지시 부족·출력 적체·상대 음성 인식과
잡음/에코 중 어느 부분이 원인인지는 분리 시험이 필요하다. 사용자 발화마다 단순 음량 기준으로
clear를 보내면 짧은 맞장구나 에코에 잘못 반응하고 다음 유효 응답도 잘릴 수 있다.

한국어 개선의 첫 후보는 일상적인 존댓말, 짧은 문장, 과한 안내 방송식 억양/반복 대기 멘트 줄이기,
시간·날짜·이름의 발음 예시다. Sol이 돌려주는 최종 발화 문구도 함께 평가해야 한다.
같은 한국어 입력에서 현행/개선 지시를 비교하고, 기본 음성과 endpoint가 허용한 다른 음성을 비교한다.
모델 언어 능력 자체가 향상된다고 주장하지 않고 발음·억양·상호작용 체감으로 평가한다.

수정 시에는 재생 중단 지연·한국어 이해/발음·끼어든 뒤 답변 문맥·자동 종료 회귀를 별도로 검증한다.
현재 운영 프롬프트·모델·음성·음성 중계 코드는 변경하지 않았다.
